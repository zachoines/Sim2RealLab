# Constraints for the Isaac Sim / Isaac Lab conda environment.
#
# Generated from the pip freeze of the environment that Stage 3 validated:
# the 282 `name==version` lines of that freeze, with the 17 editable installs
# and the one git-URL requirement (robomimic) dropped — a constraints file
# cannot pin an editable or a URL requirement, and pip rejects the file if it
# tries.
#
# What this is for: the recipe in README.md pins about fifteen packages by
# name. The other ~267 are whatever the resolver returned on the day, and they
# do move — a rebuild eleven days later drew ten different versions, including
# usd-exchange across a major version. This file is how a rebuild gets the
# resolved set rather than a contemporary one.
#
# How far this is proved: the file parses, and the constrained resolutions were
# checked by dry-run. A full rebuild under these constraints has NOT been run
# end to end. Two things are known to need care and are described in README.md
# under the recipe:
#   - the torch steps need `--extra-index-url https://pypi.org/simple`, because
#     the cu130 index alone cannot supply the constrained transitives;
#   - `isaaclab.sh --install` must run OUTSIDE PIP_CONSTRAINT, and be followed
#     by a convergence pass, because it uninstalls torch before re-pinning it
#     and fails under a constraint that names the version it just removed.
